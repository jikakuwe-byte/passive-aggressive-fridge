One note from a passive-aggressive fridge, four days into its human's "healthy eating" era: the cake is gone, the salad is wilting untouched, and the fridge has questions about the 2 a.m. cheese. Running the program prints the note, and nothing else.

## Run it

```sh
node main.ts
```
